# Example commit workflow

1. Read the Task objective, acceptance criteria, dependencies, and frozen Run
   configuration.
2. Preserve unrelated changes and work only in the assigned Workspace.
3. Run the focused checks declared by the repository.
4. Commit one cohesive change with a concise English message.
5. Report the exact Candidate commit; do not push, publish, integrate, clean
   lifecycle resources, or close the Task.
