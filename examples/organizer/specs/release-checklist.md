# Example release checklist

- The Task targets exactly one Workspace.
- Every prerequisite is satisfied or has an explicit audited human override.
- Acceptance criteria identify observable outcomes.
- The Candidate is one exact clean commit descending from the current base.
- Authoritative Linux CI and independent Review bind that exact Candidate.
- Human feedback is resolved and integration remains manual.
- Cleanup preserves ambiguous or unintegrated state.
