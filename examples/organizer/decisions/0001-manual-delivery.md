# Decision 0001: Keep integration manual

- Status: accepted
- Scope: example Project

The example Project uses pull-request delivery with manual integration. A
human inspects the exact Candidate, authoritative Linux CI, independent Review,
feedback, and mergeability before submitting the separately authenticated
integration action.

This record describes Project intent. It cannot authorize a merge or replace
the active `paseo-director.json` Preview/Apply process.
